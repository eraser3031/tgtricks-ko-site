용어정의
AsyncDisplayKit(ASDK)Facebook이 오픈소스로 공개했고 이후 Texture로 이름이 바뀐 비동기 UI 프레임워크예요. Telegram-iOS는 자체 포크를 유지하며 ASDisplayNode로 백그라운드 스레드에서 레이아웃과 그리기를 해요
TGUIKitTelegramSwift의 자체 UI 라이브러리예요. AppKit으로 UIKit의 뷰, 리스트, 내비게이션 관습을 재현해요
비공개 APIApple SDK 헤더에 선언되어 있지 않은 클래스, 메서드, selector 또는 KVC 키
KVCKey-Value Coding이에요. 문자열 키로 객체 속성을 읽고 쓰며, 비공개 속성도 이렇게 접근할 수 있어요
IMPObjective-C 메서드의 함수 포인터예요. IMP를 얻으면 C 함수처럼 호출하거나 자체 구현으로 바꿔 끼울 수 있어요
메서드 스위즐링(swizzling)런타임에 특정 selector에 대응하는 IMP를 맞바꾸거나 다른 것으로 바꿔 끼우는 일
ISA 교체런타임에 객체의 클래스 포인터를 자동 생성한 서브클래스로 바꿔서 개별 인스턴스의 동작을 바꾸는 일
Portal같은 레이어 내용을 다른 위치에 보여 주는 비공개 메커니즘이에요. 예: _UIPortalView, CAPortalLayer
CABackdropLayer자기 아래에 있는 화면 내용을 샘플링하는 비공개 레이어예요. 시스템 반투명 블러(frosted glass)의 하위 구현이에요
CAFilterCore Animation의 비공개 필터 클래스예요. 가우시안 블러, 컬러 매트릭스, 디스플레이스먼트 맵 같은 효과를 만들 수 있어요
additive 애니메이션isAdditive = true인 애니메이션이에요. 값이 모델 값 위에 더해지므로 이전 위치에서 새 위치로 부드럽게 따라잡을 수 있어요
presentation layer레이어가 지금 화면에 보이는 상태예요. 애니메이션을 중단할 때 여기서 시작점을 가져오면 튀는 현상을 피할 수 있어요
디스플레이 링크CADisplayLink(iOS) 또는 CVDisplayLink(macOS)예요. 화면 주사율에 맞춰 콜백해요
IOSurface프로세스와 GPU 사이에서 공유할 수 있는 픽셀 버퍼
Swift 작은 문자열15바이트 이내의 Swift String은 별도 메모리 할당 없이 머신 워드 두 개에 바로 저장돼요. 컴파일 후에는 즉치값 형태로 나타나는 경우가 많아요
MOVZ/MOVKarm64에서 16비트 즉치값을 레지스터의 지정한 위치에 쓰는 명령어예요. 짧은 문자열은 흔히 이 명령어로 조립돼요
FairPlayApp Store가 iOS 실행 파일에 적용하는 암호화예요. 그래서 iOS 릴리스 빌드는 바로 정적 분석을 할 수 없어요
hardened runtimemacOS의 런타임 보호예요. 켜져 있으면 get-task-allow가 없는 프로세스에는 디버거를 붙일 수 없어요
ad-hoc 서명개발자 인증서를 쓰지 않는 로컬 서명이에요. 수정한 사본을 로컬에서 실행할 때 써요
CGEvent tap시스템 이벤트 스트림에 끼워 넣는 리스너예요. 다른 앱의 키보드와 마우스 이벤트를 받을 수 있어요
리소스 포크, FinderInfoHFS+/APFS 파일의 부가 데이터 스트림과 Finder 메타데이터 비트예요. Telegram은 이걸로 자기 bundle에 커스텀 아이콘을 설정해요
Evidence IDREA가 분석 출력마다 만드는 콘텐츠 해시예요. 결과를 다시 확인할 때 써요

연구 범위의 한계

  • 이 사이트의 내용은 공개 소스 코드의 정적 분석과 macOS 13.0에 대한 한 차례의 바이너리 검증에서 나왔어요.
  • 런타임 관측은 시작 화면과 로그인 화면만 다뤄요. 계정에 로그인하지 않았고 채팅 화면에도 들어가지 않았어요.
  • iOS 부분은 전부 소스 분석이고 바이너리 검증은 하지 않았어요.
  • 항목에 나오는 비공개 API 사용은 기술 연구 목적으로만 다뤄요. 가져다 쓰기 전에 위험과 차용 가능성을 먼저 참고해요.
